# 《老板，真塞不下了！》操作与规则说明

版本：0.1 · 日期：2026-11-03 · 状态：原型实现基线

适用范围：3 关基础拼装原型。游戏方向和版本范围见 [游戏设计总纲](GameDesign.md)。本文约定可观察行为；像素阈值、动画时长和触摸偏移量留作真机调优。

## 1. 基础定义

- 棋盘：车厢可用格与禁用格的集合。逻辑坐标以左下为原点，向右为 X 正向，向上为 Y 正向。
- 货物形状：局部整数格集合。旋转后平移归一，使最小 X、Y 均为 0；位置表示局部包围盒左下角对应的棋盘格。
- 朝向：0、90、180、270 度，每次按钮操作顺时针旋转 90 度。对称形状允许操作，但不强行改变外观。
- 货物实例：订单中的一件独立货物，相同形状的两个纸箱也分别计数。
- 已提交布局：上次成功放置后正式记录的布局。拖动预览不属于已提交布局。
- 拖动事务：从拿起到成功放下或取消的一次操作，保存起点、原朝向和原所属区域，用于完整回退。

## 2. 界面与输入

- 竖屏布局：上部订单简讯，中部车厢，下部待装区；旋转、重置和暂停按钮不能遮挡棋盘。
- 鼠标左键与单指触摸共享操作语义。仅处理第一个有效指针；第二指针不能抢走货物或触发按钮。
- 点中货物实际占用的格子区域才可选中，不用 L 形等货物的整个矩形包围盒阻挡其他货物。
- 按下后超过拖动距离阈值才进入拖动；未超过则按点击处理。阈值考虑屏幕缩放，避免轻触抖动被当作拖动。
- 点击货物选中并高亮；点击空白区域清除选中。点击操作按钮本身不先清除选中。
- 原型不支持双指旋转、长按菜单或自由角度旋转。

## 3. 拖动、落点与吸附

1. 在待装区或棋盘上按住货物并移动，建立拖动事务。
2. 保留抓取点相对货物的位置，触摸时额外向上抬升显示，让手指下方的落点可见；鼠标可以不抬升。
3. 从货物的显示位置换算候选锚点，吸附到最近整数格；半格边界使用固定取整规则，避免相同位置来回跳动。预览与松手提交必须使用同一个候选坐标。
4. 货物包围盒与车厢显示区域相交时显示候选预览；超出边界的部分仍参与越界检查，不自动把货物挤回车厢内。
5. 合法候选显示有效轮廓与标识；非法候选显示无效轮廓与标识。预览不占用格子，不触发通关。
6. 松手后：合法车厢候选提交放置；在明确的待装区松手则存回待装区；其他情况取消并回到拖动起点。

区域判定以显示货物的包围盒中心为准，不以被手指遮挡的触点为准。界面布局须让棋盘与待装区分离；中心位于两区之间时，允许提交合法棋盘候选，否则回退。提示图形与实际判定应共享同一几何结果。

拖动期间旋转按钮禁用，松手后通过选中状态旋转。不要求玩家一指拖动、一指点击按钮。

## 4. 选中与旋转

### 待装货物

- 点击后选中，旋转按钮可用；每次点击更新朝向并重新适配其展示槽位。
- 待装槽位仅用于展示，不作为车厢占格规则；不能因旋转遮挡其他货物或使其不可点击。
- 再拖入车厢时使用当前朝向。

### 已装货物

- 点击后选中，旋转按钮可用。
- 以归一化包围盒左下锚点保持不变，计算新朝向；校验时排除该货物自己的原占格。
- 新朝向合法则原子更新布局；不合法则保持原位置与朝向，并显示简短无效反馈。
- 不尝试自动平移寻找空位。玩家需要换位置时，先取出或重新拖动。
- 每次有效旋转后重新检查通关；不可旋转货物未来若启用，应显示限制原因，不能让按钮看起来失灵。

## 5. 合法性与重新摆放

货物在候选锚点与朝向下，必须同时满足：

1. 每个占用格都在棋盘边界内。
2. 每个占用格都是可用格。
3. 每个占用格都没有被其他货物占用。

原型不添加重力、重量、支撑、易碎、冷藏或装车顺序限制。

拿起已装货物时，原占格从当前碰撞计算中临时释放，但保留事务快照。拖动期间暂停通关检查。提交时一次更新位置与占格；取消时恢复原位置、原朝向和原占格。因为只有一个有效指针，期间不允许另一件货物占用原位置。

非法松手只回退当前操作，不影响其他货物。货物回到待装区后恢复可取用状态，不能被销毁或生成副本。原型不制作独立“撤回上一步”按钮，免费重放与重置已提供基础恢复能力。

## 6. 常见操作结果

| 输入或场景 | 预期结果 |
| --- | --- |
| 点击待装或已装货物 | 选中，显示清晰轮廓，启用旋转 |
| 拖入合法格并松手 | 更新布局，播放轻量吸附与放置反馈，保持选中 |
| 拖到重叠、禁用或越界位置松手 | 恢复拖动起点，短促无效反馈，保持选中 |
| 把已装货物放回待装区 | 移除正式占格，恢复待装展示，保持当前朝向与选中 |
| 在车厢以外且不属于待装区松手 | 取消，恢复拖动起点 |
| 点击旋转但新姿态不合法 | 不修改布局和朝向，显示失败反馈 |
| 拖动中收到输入取消或失焦 | 回滚事务，清除预览和指针捕获 |
| 第二指针触摸 | 忽略，不取消第一指针 |
| 货物吸附动画中再次按住 | 按逻辑最终位置命中，结束旧动画并开始新操作 |

## 7. 暂停、后台、重置与退出

- 暂停：若有拖动先回滚，再展示暂停界面，清除选中和预览。底层棋盘不接受输入。
- 切后台或失焦：执行相同的拖动回滚与暂停。回到前台后由玩家点击继续，不自动恢复未完成拖动。
- 重置：按钮仅在无拖动时可用，点击后显示确认，避免误触。确认后恢复当前关所有货物的初始区域与朝向，清除选中及预览；取消不改变布局。
- Android 返回操作：游戏中打开暂停；暂停中关闭暂停；重置确认中只关闭该确认框。通关反馈期间不退回可编辑布局。
- 原型暂停菜单提供继续、确认重置和返回主菜单；返回主菜单丢弃当前摆放，再次开始从第 1 关进入。结算也提供返回主菜单入口。
- 原型不保存关卡中间布局；应用被系统结束或重启后从第 1 关开始，不承诺恢复现场。完整版本退出与存档策略后续单独设计。

## 8. 通关与关卡切换

- 仅在成功提交布局后判断：订单中的全部货物实例均在车厢内，且布局合法。
- 不以填充率、参考解相等、预览位置或货物图像是否覆盖车厢判断通关。
- 满足条件后立即锁定为完成状态，取消选中，禁用棋盘编辑和重置；最后一件落地约 0.12 秒后播放完成短音效和印章，再经过配置中的展示间隔（默认 0.85 秒）显示结算。表现延迟不延迟逻辑通关。
- 每次关卡运行只触发一次完成事件；重复输入或重复动画回调不得重复结算。
- 结算显示完成与下一关。最后一关显示“原型体验完成”与“从头重玩”。原型不展示无用途工资或广告按钮。
- 下一关或重玩应清除旧货物、旧预览、事务和完成标记；重玩创建一次新的关卡运行。

## 9. 反馈与可读性

- 选中轮廓、拖动实体、落点预览分层清楚，预览不能被货物图完全盖住。
- 有效与无效状态使用颜色搭配轮廓或符号区分；禁用格也有独立纹理或标记。
- 无效反馈只在松手或主动旋转失败时播放，不在拖动经过每个非法格时持续响。
- 音效与震动/弹性可在暂停弹层关闭并保存偏好；画面震动不移动命中矩形或棋盘逻辑坐标。反馈资源与调节方式见 [反馈说明](FeedbackDesign.md)。
- 触摸抬升与吸附反馈以手机测试确定。不得为了动画延迟提交逻辑，或让画面与命中区域长时间分离。
- 教学只在相关关卡首次操作前给简短提示，允许直接操作，不反复弹窗打断。

## 10. 验收用例

| 检查 | 通过条件 |
| --- | --- |
| 四边越界与禁用格 | 任一实际占格不合法就不能提交 |
| 非矩形形状 | 凹口不算占格，不阻挡位于凹口的其他货物 |
| 连续四次旋转 | 空间允许时恢复初始形状与锚点，无坐标漂移 |
| 已装货物自旋转 | 不与自己冲突；与其他货物冲突时完整保留原布局 |
| 抓取位置变化 | 从货物不同部位抓取都不突然跳到手指中心 |
| 非法回退 | 待装与已装货物都恢复起点，不丢失占格 |
| 待装区取回 | 取回后旧格可用，同一实例可以再次装入 |
| 多指、失焦、暂停 | 无悬空事务、残留预览或第二次放置 |
| 最后一件预览 | 预览时不通关，合法松手后只通关一次 |
| 非参考摆法 | 只要全部合法装入，同样通关 |
| 重置和重玩 | 状态完全恢复，无旧事件重复触发 |
| Android 屏幕适配 | 棋盘、全部货物、按钮可见且可操作，不与安全区域冲突 |

几何和占格规则适合自动测试；拖动阈值、显示偏移、遮挡和反馈强度必须进行真机人工验证。
