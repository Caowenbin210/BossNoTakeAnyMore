# 《老板，真塞不下了！》游戏设计总纲

版本：0.1 · 日期：2026-11-03 · 状态：原型设计基线，待真机试玩验证

本文定义游戏方向、版本范围与完成标准。具体输入和边界行为见 [操作与规则说明](InteractionRules.md)。后续调整应同步更新相关文档。

## 1. 游戏定位

一款面向安卓手机的 2D 竖屏休闲空间整理游戏。玩家扮演准备下班的仓库管理员，通过拖动、旋转和重新排列不同形状的货物，把一张订单的所有货物装进有限的车厢。

- 核心体验：观察杂乱货物，发现摆放关系，最终把最后一件稳稳装进去。
- 主题情绪：打工人的轻松吐槽，完成任务的满足感，不制造持续催促和惩罚。
- 宣传文案：“装完这车就下班……老板，你怎么又来一车？”
- 目标场景：碎片时间游玩，随时暂停；单关时长先以约 1～3 分钟为设计假设，通过试玩修正，不作为硬限制。
- 平台目标：先提供可安装的 Android APK，后续面向 TapTap 发布并接入自愿激励广告。发布资质和 SDK 接入另行验证，不属于玩法原型验收。

## 2. 设计原则

1. 操作顺手：单指完成主要操作，货物与落点清晰，误放可恢复。
2. 规则可信：可见格子与实际判定一致，旋转、吸附和回退行为稳定。
3. 成功有反馈：最后一件装入后，让玩家看清完整布局，再进入结算。
4. 挑战公平：每关开始展示全部货物，至少存在一个合法解；所有合法解均可通关。
5. 内容克制：先验证基础拼装，每次只引入一种新机制。

## 3. 核心循环

查看订单与全部货物 → 观察车厢 → 拖动、旋转、试放 → 必要时重新整理 → 全部装入 → 装车反馈与工资结算 → 下一张订单。

老板追加订单只发生在下一关或转场，不在当前关卡临时添加货物、改变答案条件。玩家已经完成的订单保持完成。

## 4. 基础玩法

### 4.1 空间与货物

- 车厢是俯视、单层、固定大小的正交格子区域，可以配置不可用格子。
- 每件货物由若干相连的完整格子组成，原型使用方形、长条、L 形等少量清晰形状。
- 货物只能按格放置，不支持半格、斜放、镜像、缩放或上下堆叠。
- 可旋转货物每次旋转 90 度；原型全部货物允许旋转。未来如限制旋转，必须明确展示标识。
- 货物不可重叠，不可占用禁用格，不可超出车厢。
- 所有订单货物从开局就可见，待装区不能通过滚动隐藏关键货物。

### 4.2 胜负与恢复

- 每个订单货物实例都合法放入车厢，即通关；不要求填满车厢，也不要求匹配参考解。
- 基础关卡无倒计时、无操作次数限制、无生命值消耗。
- 无法继续时允许免费取出、旋转、重放或重置。非法操作不扣钱、不损坏货物。
- 原型不设置失败结算；限时挑战与失败加时属于后续范围。

## 5. 关卡方向

原型制作 3 关，每关验证一个主要目标：

| 关卡 | 教学目标 | 设计要求 |
| --- | --- | --- |
| 1 | 拖动与放置 | 留足空间，无需旋转也能完成，提供简短拖动提示 |
| 2 | 旋转 | 至少一件货物必须改变初始朝向，突出选中与旋转按钮 |
| 3 | 重新整理 | 引导玩家尝试替代布局，体现长条或 L 形货物对剩余空间的影响 |

每关保存一个参考解，供可解性验证与未来提示使用。第 3 关不要求所有玩家必须撤回一次，只需支持并鼓励调整。前 3 关的尺寸、货物、参考解与教学流程见 [关卡设计](LevelDesign.md)，不能仅凭占格总面积判断可解。

后续扩到 20 关时，按空间宽松度、形状组合、禁用格布局逐步增加挑战。避免只增加货物数量或连续要求严丝合缝。特殊规则优先考虑冷藏区域、方向限制等可由二维格子清楚表达的条件；“易碎品不能被压”暂缓，直到设计出清楚的堆叠规则。

## 6. 视觉、声音与叙事

- 风格：明快、清爽的卡通仓储场景，轮廓清楚，背景弱化。
- 原型：使用色块、格线、形状图标与文字，不等待正式美术。
- 货物画面须与实际占格一致，装饰不能遮挡形状和预览。
- 合法与非法预览同时使用颜色和轮廓/符号，不能只依赖红绿色差。
- 反馈重点：拿起、旋转、成功放置、非法放置、通关；动画不改变规则或阻塞连续操作。
- 老板台词简短、可跳过，不遮挡棋盘，不要求玩家读完才能操作。
- 订单幽默来自货物组合和描述，例如“就几件小东西”对应沙发、冰箱和发财树；避免用隐藏规则制造笑点。

## 7. 成长与广告原则

- 完整版本按通关解锁后续关卡，不用工资购买主线通行权。
- 工资拟用于非必要装饰；具体用途和数值待核心玩法验证后确定。
- 原型结算仅展示完成和下一关，不制作工资消费系统或广告界面。
- 后续预留激励广告服务：可考虑提示、限时关加时、结算额外工资；奖励用途明确后再开放入口。
- 广告由玩家主动选择，基础拖动、旋转、重放、重置免费，正常通关不依赖广告。
- 原型不接真实广告 SDK。正式接入时需处理加载失败、取消观看与奖励重复回调，并按实际接入服务准备发布资料。

## 8. 版本范围

### 第一阶段：可玩原型

- 一个可直接进入游戏的场景，3 个可切换的关卡。
- 拖动、选中旋转、吸附预览、合法性检测、取出重放、重置。
- 简短操作引导、暂停、通关反馈和下一关入口；最后一关显示原型完成及重玩入口。
- 使用配置定义货物和关卡；完成一次 Android 真机操作检查。
- 不要求重启后保留进度，可从第 1 关重新开始。

### 第二阶段：小型完整版本

核心操作通过试玩后再制作：主菜单、选关、20 关、正式引导、本地进度与设置存档、工资结算、正式美术音频、屏幕适配，以及经验证的广告与发行接入。限时关和装饰系统是否纳入首发，届时依据时间与试玩结果决定。

### 暂不制作

联网排行榜、多人、内购、复杂经营、自由物理堆叠、无限随机关卡、后台服务、体力系统、强制插屏广告。

## 9. 原型验收

- 3 关均可从头完成，参考解通过相同放置规则验证。
- 鼠标与安卓触摸均可完成核心操作；不要求双指配合。
- 旋转、拖出重放和非法回退不出现丢件、复制、重叠占格或无法选中。
- 最后一件合法装入后只结算一次，拖动预览不能触发通关。
- 暂停、切后台与重置不会留下拖动残影或错误占格。
- 手机上能看清全部货物、棋盘与落点，操作按钮不被系统安全区域遮挡。
- 观察试玩者是否理解旋转、能否预测落点、是否愿意继续下一关。若主要困难来自操作，应先修操作再扩关。

## 10. 待试玩确定

棋盘尺寸、单格物理显示大小、拖动抬升距离、吸附阈值、动画时间、关卡具体布局和难度曲线均需调优。当前文档不承诺开发工期、广告收益或发行审核结果。
